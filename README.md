# Dead by Daylight Fan Site

This is my website project for CISS155 Web Development 1 at Olympic College.

The website is based on the video game Dead by Daylight, which I have played since 2016 and have over 1,000 hours in.

## Features
- Multi-page website
- Custom CSS styling
- Responsive layouts
- Hover effects
- Killer information page
- GitHub Pages deployment
