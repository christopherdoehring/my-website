# Dead by Daylight Fan Site

This is my website project for CISS155 Web Development 1 at Olympic College.

The website is based on the multiplayer horror game Dead by Daylight, which I have played since 2016 and have over 1,000 hours in.

The goal of this project is to create a responsive multi-page fan website while practicing HTML5, CSS3, Flexbox, CSS Grid, responsive web design, and GitHub Pages deployment.

## Features
-Multi-page website
-Responsive layouts
-CSS Flexbox layouts
-CSS Grid layouts
-Hover animations and effects
-Interactive survivor flip cards
-Killer information database
-Responsive navigation menu
-Mobile and tablet media queries
-Background images and custom styling
-GitHub Pages deployment
-Website Pages

## Home Page
The homepage introduces Dead by Daylight and explains the basic gameplay and themes of the game.

## Killers Page
The killers page contains a large grid layout of Dead by Daylight killers with:
-Character images
-Hover effects
-Responsive grid layouts
-Fixed sidebar navigation
-Same-page anchor links

## Survivors Page
The survivors page explains survivor gameplay and includes:
-Responsive flexbox layouts
-Survivor information cards
-Interactive flip card animations
-Grid-based survivor layouts
